# تجربة السوق الحالي — استكشافية فقط

هذا التشغيل مستقل عن فوج الـ90 يوماً، ولا يغيّر مواعيده أو بصمته. يختار حدث BTC اليومي القادم قبل 12:00 نيويورك، ويحتفظ بكل عتبات الحدث، لا أفضل عقد بعد رؤية النتائج. ليس سوق BTC خمس دقائق؛ ذلك المسار ما زال يحتاج مرجع افتتاح موثوقاً.

التنفيذ pairbot.daily_live_preview: 12 جولة بفاصل مخطط 10 ثوانٍ، HTTP GET فقط للبيانات العامة. المدخلات الأصلية والأخطاء محفوظة في journal ذي سلسلة hash، وsummary يحوي كل نقطة. لا محفظة ولا توقيع ولا أمر حقيقي أو افتراضي ولا استبدال مرجع Binance بـCoinbase.

قبل الاطلاع على نتائج هذا التشغيل، القواعد ثابتة: نفس نموذج التوقع ذي 25 شمعة ساعة مغلقة، ونفس حدود الساعة وRTT وانحراف وصول زوج الكتب في السياسة اليومية. عينتان من NTP في بداية الجولة 0 و6، والشموع تُجلب في هاتين الجولتين؛ تُستعمل آخر ساعة مغلقة، لا ticker آني أو شمعة غير مكتملة. بيانات الرسوم والـuniverse تُجلب قبل الجولات، ولا تحمل ادعاء تحديث الرسوم المستمر. زمن الاستلام HTTP body completion لا وقت وصول socket الفعلي.

المقارنة المعلوماتية لكل جهة تستخدم احتمال النموذج ناقص ask ناقص رسم taker للسهم ناقص هامش انزلاق 0.005. الكمية المرجعية خمس أسهم، وأقل فارق 0.03، وعمق ask لا يقل عن خمس أسهم. رسم taker يُقرأ من CLOB fd ويطابق Gamma والـtoken IDs؛ الحساب C × rate × p × (1-p)، مع تقريب لأعلى إلى خمسة منازل بشكل محافظ. هذه مقارنة بعد رسم الشراء المحدد، **قبل التكاليف الأخرى المجهولة**، وليست عائداً صافياً ولا ميزة مثبتة. كل المقارنات YES وNO وجميع العتبات تظهر؛ ليست تجارب ضبط إضافية للنموذج.

وجود informational_candidate يعني أن اللقطة تجاوزت هذه المقارنة فقط؛ financial_action يبقى ABSTAIN، fills=0، realized_pnl وnet_payoff=null. لا شراء مفترض لمجرد توفر سعر، ولا mark-to-market لاستثمار لم يحدث. polling لا يثبت استمرار الفرصة بين اللقطات ولا دقة التوقع أو الربح عند التسوية. لا يتم تعديل معايير القبول أو تشغيل الاختبار النهائي القديم.

التشغيل:

```sh
python -m pairbot.daily_live_preview
```

لا overwrites لمجلد تشغيل موجود. Workflow live-preview.yml يشغله على الفرع البحثي عند تغيير ملف التجربة/الـworkflow فقط؛ تحديث التقرير لا يشغل جلسة أخرى. النتائج تبقى استكشافية حتى لو كانت البيانات حقيقية. لا تُقبل هذه الملفات في أرشيف الفوج الحقيقي.
