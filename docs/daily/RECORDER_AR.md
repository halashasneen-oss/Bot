# مسجّل التوقع اليومي — الحالة الحالية

نُفذ pairbot.daily_recorder مع journal سببي مستقل. لم يبدأ التسجيل الحقيقي ولم يُنشأ cron أو automation. البداية المجمدة 6 أكتوبر 2026، وموعد ذلك اليوم 06:00 نيويورك = 10:00 UTC = 13:00 عمّان. يومياً يُحسب الموعد من America/New_York، بما يشمل تغيير التوقيت الصيفي.

## التشغيل

مع الوصول الشبكي العام والتبعيات الحالية:

```sh
python -m pairbot.daily_recorder --day 2026-10-06 --output runs/daily-prospective
```

الناتج runs/daily-prospective/2026-10-06/journal.jsonl. الأمر ينفذ محاولة واحدة دون إعادة طلب أو تجاوز حجب. إذا نفذ خارج ±30 ثانية من وقت القرار، يحفظ missing_day وsealed دون طلب بيانات، ولا يعيد بناء توقع سابق. الأيام خارج الفوج ترفض قبل أي شبكة أو كتابة. اليوم الموجود لا يُكتب فوقه؛ إعادة التشغيل لا تستبدل التوقع الأصلي.

أضيف workflow يدوي daily-recorder.yml، دون schedule أو trigger على push. إتاحة workflow_dispatch في واجهة GitHub تتطلب وجود تعريفه على default branch، ولذلك الملف على فرع المراجعة لا يعني أن مهمة تعمل الآن. لا merge نُفذ.

## ما يحفظه

- policy hash وcommit التجميد في header، وسلسلة SHA256 متتابعة مع flush وfsync لكل سجل.
- قياسي NTP المحددين مسبقاً، كلاهما محفوظ؛ آخر إزاحة مع أكبر عدم يقين، دون انتقاء الأقل. هذا توقيت بحثي مشروط لا اعتماد للساعة في البروتوكول القديم.
- استجابة Gamma كاملة وقواعد كل عقد، وقائمة جميع الأسواق قبل التعامل معها. حصر شرط exact rules وquestion/slug threshold وموعد endDate وtoken IDs؛ القواعد الجديدة أو غير المطابقة تؤدي إلى الامتناع، لا التخمين.
- شموع Coinbase كاملة كما وردت، مع الاقتصار على 25 شمعة ساعة مكتملة ومتتابعة. الطرف المحافظ لنافذة UTC يستخدم عدم يقين الساعة لمنع إدخال شمعة قد تكون لم تُغلق بعد.
- تفاصيل CLOB الرسومية ودفتر الطرفين، وأوقات إرسال/اكتمال جسم HTTP قبل JSON وRTT وhash الجسم الخام. وقت HTTP ليس وصول socket.
- احتمال p_yes وmidpoint للمقارنة في النقاط التي اجتازت الفحوص، أو null مع سبب الامتناع. جميع السجلات تبقى ظاهرة؛ clean_point تصنيف وصفي ولا يمنح GO.
- sealed بعد اكتمال المرور، بدون قراءة نتائج أو حساب عائد. جميع الأفعال المالية ABSTAIN بسبب الكلفة المجهولة، وfills=0 والعائد null.

السلسلة تكشف تعديل محتوى دون إعادة حساب البصمات، لكنها ليست توقيعاً أو دليلاً مستقلاً على وقت الإنشاء. لقبول سجل حقيقي مستقبلياً، يلزم أرشيف خارجي ذو وقت خادم قبل الهدف/النتيجة، مثل GitHub Artifact في run موثق بcommit السياسة. لا تكفي كتابة created_at محلياً. احتفاظ artifact لمدة 90 يوماً لا يضمن بقاء أول يوم حتى ما بعد انتهاء الفوج؛ يجب حفظ checkpoints دائمة في Git قبل انتهاء الصلاحية، دون تعديل السياسات أو السجلات الأصلية.

## القيود المتبقية

هذا المكون مسجّل توقعات؛ أضيفت مكونات مستقلة لجمع النتائج والتقييم وbootstrap في COMPLETION_AR.md، دون حساب أداء حقيقي الآن. لم تبدأ تجربة الـ90 يوماً. ولأن معايير الاختيار المالية لم تكتمل بالكلفة الموثقة، لا توجد اختيارات YES/NO مالية ولا GO مالي حتى لو ظهر احتمال قوي.

القراءة من REST ليست تغطية مستمرة، والطلبات للطرفين غير ذرية. البقاء ضمن فرق الاستلام المحدد لا يثبت تزامن السوق أو تعبئة. رفض النقطة بسبب دفتر جهة واحدة أو نقص metadata محفوظ كسبب، ولا يُحذف اليوم أو تُعدَّل العتبات لإدخاله. اختلاف Coinbase عن Binance يبقى فرضية نموذجية غير معايرة.

الاختبار النهائي القديم وبصمات السياسات المجمدة ونموذج التعبئة بقيت كما هي.

## التحقق

259 اختباراً ناجحاً محلياً، بينها 19 اختباراً جديداً لسببية الزمن، الرسائل المستقبلية، الانحراف/قفزة الساعة، الفجوات، تغير قواعد العقد، عبث journal، عدم الكتابة فوقه، رفض خارج الفوج، والتعامل مع DST واليوم الفائت دون طلب شبكة. اختبارات التوقع تستخدم مدخلات اصطناعية فقط، ولا تقاس كفرص أو أرباح.
