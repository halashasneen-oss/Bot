# Momentum v1 — محاكاة فقط

تنفيذ جديد داخل المستودع الحالي، دون تغيير الاستراتيجيات القديمة أو نتائجها.
قرار واحد لكل نافذة BTC خمس دقائق عند T-120 ثانية ±5 ثوانٍ، وحركة >=80 دولار
تحدد Up أو Down باتجاه الحركة فقط. لا نموذج احتمالات أو تقلب أو مؤشرات إضافية.
تُفحص بيانات Chainlink TWAP المطابقة لمصدر تسوية السوق، مع افتتاح دقيق مسجل
سببيًا عند بداية النافذة. لا Binance ولا إعادة بناء افتتاح مفقود من بيانات لاحقة.

config.yaml للقراءة فقط؛ يرفض البرنامج أي تغيير في القيم الست المجمدة.
live=false، ولا يوجد مسار تداول حقيقي أو قراءة مفاتيح حتى عند CONFIRM_LIVE=YES.
هذه هي نسخة PAPER التي وافق المستخدم على تجهيزها الآن.

التوضيحات المعتمدة: ميزانية 5 دولارات تشمل رسوم الدخول؛ التأخير ثابت ثانيتين؛
قواعد السوق الحالية تحدد Chainlink TWAP60 مصدرًا، لذا الافتتاح والسعر عند القرار
من crypto_prices_twap_sixty نفسه. اشتراك RTDS يطلب btc/usd فقط، ويُرسل filters
كسلسلة JSON مضغوطة كما يتطلب الخادم، بدل استقبال جميع العملات. بيانات السوق
تُفحص في كل نافذة وأي مصدر آخر أو رسوم غير متحققة ينتج عنه امتناع.

تُشترى ميزانية كاملة من مستويات asks، ومتوسط السعر VWAP <=0.90؛ الحد على
المتوسط وليس على كل مستوى منفرد. يُعاد فحص العمق والسعر وحداثة البيانات بعد
الثانيتين، وتُستخدم أسعار ما بعد التأخير فقط للتعبئة الورقية. إشارة الحركة
تُقيّم مرة واحدة ولا يعاد اختيار الجانب. الرسوم تطابق Gamma/CLOB، وتقرب للأعلى
لكل مستوى والأسهم للأسفل إلى ست منازل، مع غبار ميزانية أقل من 0.0001 دولار.
لا تعبئة جزئية، ولا إثبات تنفيذ حقيقي من العمق المعروض، ولا أوامر فعلية.

تُحتفظ الصفقة إلى التسوية الرسمية resolved/payouts، وليس لمس السعر 0 أو1.
إذا لم تُسوّ عند نهاية الموعد تبقى PENDING، ولا نختلق نتيجة أو نبيع مبكرًا.
النقد المحجوز في صفقة مفتوحة لا يعتبر خسارة محققة لحد الرصيد؛ حد30 يطبق على
الرصيد بعد التسوية. حد الخسارة اليومية -10 حسب تاريخ UTC للتسوية.

عند لحظة القرار يبقى شرط حداثة المرجع <=2 ثانية كما هو دون أي توسيع. إذا كان
آخر tick أقدم من ذلك، ينتظر البرنامج tick حيًا صالحًا فقط داخل نافذة القرار
الأصلية T-120 ±5 ثوانٍ؛ فإذا انتهت النافذة دون مرجع صالح تُسجل النافذة
stale_reference وتُتخطى، من دون إعادة تقييمها ومن دون تغيير أي عتبة.

ثلاثة إخفاقات متتالية في قناة API أو websocket أو فحص تنفيذ حقيقي توقف الجلسة،
ولا تخفي طلبات HTTP الناجحة سلسلة فشل websocket. stale_reference وحده امتناع
بيانات خاص بالنافذة وليس فشل تنفيذ قاتل، بينما stale_book والحالات المبهمة
الموجودة أصلًا تبقى ضمن فشل التنفيذ. العودة لتدفق BTC صالح تكسر سلسلة فشل
الاتصال؛ الامتناع العادي للحركة/السعر/العمق ليس إخفاق اتصال. لا إعادة تشغيل
تلقائي عند التوقف.

لكل نافذة صف واحد في windows.csv بالأعمدة المطلوبة، بما فيها نوافذ بدء التشغيل
والنوافذ المفقودة. الصف المعلق يُحدَّث بعد التسوية دون إضافة صف ثانٍ. الجورنال
يحفظ الأدلة الخام وسلسلة hashes. summary.json يعرض النتائج غير المسوّاة بصدق.

تشغيل مستمر افتراضيًا بلا موعد انتهاء:

    python -m pairbot.momentum --config config.yaml --output runs/momentum-new
