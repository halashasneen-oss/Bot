# فحص نافذة BTC خمس دقائق حية

التنفيذ pairbot.five_minute_live يجمع نافذة واحدة محددة قبل معرفة النتيجة. يبدأ في الحد التالي من مضاعفات 300 ثانية بعد مهلة تجهيز 15 ثانية، ولا ينتقي نافذة ثانية حسب أداء الأولى. 31 جولة HTTP بفاصل مخطط 10 ثوانٍ، من بداية النافذة إلى نهايتها، ثم حتى ثلاث محاولات نتيجة رسمية عند نهاية+10 و+30 و+60 ثانية. timeout للمهمة 12 دقيقة؛ أي فشل يظهر في التسجيل ولا يبرر استبدال الجلسة.

المشروع PAPER ONLY: public GET و NTP تشخيصي فقط. لا مفاتيح API أو حساب أو محفظة أو توقيع أو أوامر، ولا اتصال Binance أو proxy أو التفاف. يُحفظ دفتر UP/DOWN بتعيين tokens من metadata، وليس افتراض أن الأول UP. نص قواعد العقد و resolutionSource و cryptoMarketConfig محفوظة كما وردت. كتاب أحادي أو غير مطابق لا ينتج سعر شراء/بيع صالحاً.

Gamma market/events يجمعان قبل النافذة ودوريًا خلالها وبعدها، ويحفظان وجود eventMetadata.priceToBeat و finalPrice ومصدرهما ومرحلة وصولهما. حقل افتتاح ظهر بعد النهاية لا يعاد إدخاله في توقع سابق. وجود أي حقل لا يثبت وحده مطابقته لتغذية التسوية ولا يوفر تاريخ سعر underlying المطلوب. لا يُستبدل الافتتاح بـ Coinbase أو Binance أو احتمال السوق.

عند عمر 180 ثانية (موعد السياسة الخماسية) يسجل قرار ABSTAIN صريحاً، p_up=null، بسبب غياب adapter عام مدقق للسعر underlying المطابق وافتتاح مطابق سببي والتكاليف الأخرى المجهولة. هذا فحص حي للقراءة والعوائق، وليس اختبار ربحية اتجاهي؛ لا يُدّعى تشغيل نموذج الاتجاه بلا مدخلاته. قيم UP midpoint هي احتمال السوق التقريبي لا احتمال النموذج.

التحقق من النتيجة يقبل فقط /v2/resolutions لحالة resolved مع condition مطابق و resolved_at بعد النهاية وقبل الاستلام و block موجب ودفع ثنائي برابح واحد. ترتيب Outcomes الأصلي يحدد UP/DOWN. closed أو أسعار 0/1 لا تكفي؛ الحالة المعلّقة تبقى PENDING_OR_UNSUPPORTED بلا استنتاج.

لا تغيير للسياسة المجمدة أو التعبئة أو بروتوكول القبول، ولا فتح للاختبار النهائي القديم. journal مستقل بسلسلة hash وخاتمة complete، و summary يحوي كل اللقطات والمصادر والأخطاء. fills=0 و realized_pnl=null و net_payoff=null. snapshots لا تثبت أسعاراً متصلة أو تنفيذًا افتراضياً.

الوثائق الرسمية الحالية https://docs.polymarket.com/market-data/realtime-data تتطلب authenticated SecureClient/AsyncSecureClient لتغذية prices.crypto.twap، والمثال API يرسل CLOB apiKey/secret/passphrase. لن تُستخرج هذه المفاتيح أو يُلتف على المصادقة. documentation المصدر متاح للقراءة، أما مصدر السعر العام المطابق فلم يثبت.

الأمر:

```sh
python -m pairbot.five_minute_live
```

المجلد الجديد runs/five-minute-live حصري. workflow five-minute-live.yml يعمل على الفرع البحثي عند تغيير ملف التشغيل أو workflow فقط، وليس عند إضافة تقرير. الفوج اليومي المجدول يبقى مستقلاً. النتيجة النهائية لهذا الفحص تبقى NO_GO_REFERENCE_AND_COSTS؛ النجاح التقني لجمع الأسعار لا يغير هذا الحكم.
